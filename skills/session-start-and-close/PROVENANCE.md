## Pattern evidence

Attribution: **author session history, paraphrased by reviewer, 2026-10-17**. No session transcripts were searched, read, quoted, or copied.

Reviewer estimate: about 22 starts and eight closes across six projects. Starts ask for orientation, branch/PR and task state, and blockers before work; resumes ask to reconstruct interrupted progress. Project instructions, Git hygiene, and the tracker are read first. Closes leave a next-developer note, create tracker follow-ups, ensure authorized commits, and report remaining work; pushes need authority. Confused mid-session requests receive a short concrete bulleted status.

## Adaptation and boundaries

The pattern determines concise orientation/resume/close outputs. Public source sections supply instruction discovery, sprint/task loading, quality checks, and durable handoff. Their fixed stack startup, branch model, generated tracker blocks, automatic rebase/sync, and project service teardown are not inherited. Other session-entry candidates without a verified license were not extracted; their ledger rows are marked skipped for this pass.
